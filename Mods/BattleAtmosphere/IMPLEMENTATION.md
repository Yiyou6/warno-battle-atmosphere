# 第一版实现记录

历史版本：0.2.0-test1。日期：2026-11-06。本文件保留第一版实施依据。用户随后在黑森林 4v4 征服中确认持续投入及双方高代价争夺，报告扎堆、战术单一。第二轮新增改动与边界以 [第二轮方案](TACTICS_ITERATION.md) 为准；第一版原始记录已随源码归档。

## 决策与新证据

1. 范围固定为最高难度征服与歼灭；用户明确不要操控电脑界面。本次仅文件、官方无界面构建和离线检查。
2. 从官方 base.zip 重建，旧九文件草稿完整归档。Generic、Hard 和旧的全局风险/撤退调参恢复基线。新版本八份修改均列在 Development/manifest.json。
3. 原版炮兵两个威胁门槛覆盖及一处目标偏好覆盖仅列 TresDifficile，没有 PlusDifficile。本版将最高难度纳入这些既有覆盖，不统一降低所有炮兵门槛。
4. 原地面空袭请求的三种标签没有静态匹配。新请求使用当前单位定义存在的轰炸、反坦克和凝固汽油弹飞机标签；不能据此宣称进场盘旋的执行层问题已经解决。
5. 新角色审计发现 Canon_AT_Standard、Canon_AT 都没有静态单位匹配，未将它们留在新编组的反坦克选择中。使用 Infanterie_AT、ChasseurDeChar_Standard、ChasseurDeChar，最后以 Char_Standard 作为真正有反装甲作用的替代；不把普通支援车辆当专职反坦克已满足。
6. 初始 200 CP 试算中，70 个默认卡组有 13 个三角色组合最低费用超过上限，最大 275（含运输）。混合、普通、步兵组因此使用 300 CP 上限，沿用原夺点组的预算规模；主攻仍为 600。保留 ASAP 与可选槽位，预算上限不被描述为必须攒满才出发。
7. 票券下可显式计算的三角色组合最高为 10；步兵预算由 4 调到 10，普通/合成原本为 10。6 个默认卡组部分单位或运输的票券字段未显式给出，离线工具不把缺失值擅自当 0，也不据此声称这些卡组不能玩。对应运行时计价仍待核对。
8. 已确认全局 AI 常量与策略同在 GFX/Skirmish 生成事务。旧文档“只生成 Skirmish 所以全局常量可能没打包”的疑点已解决为**包装层有证据**，仍不等于游戏加载或行为已验证。

## 十二项问题与实际处理

| 问题 | 本版实际改动 | 尚需实测 |
|---|---|---|
| P01 飞机少 | 空袭和支援任务前移、修正请求标签 | 实际出击及有效攻击，不只看买机 |
| P02 开局直升机耗尽 | 部署及其扩展不安排专门突击；14 个普通地面池不含战斗直升机；交战保留单架专门任务 | 出机用途、后期参与、防空下损失；卡组运输直升机不等于战斗直升机来源 |
| P03 炮兵少、不射击 | 提前支援炮、加入后续支援任务，最高难度纳入原有炮兵覆盖 | 射程、目标、射击、缺弹和转移后的恢复 |
| P04 防空晚 | 提前专职地面防空；取消非防空替代并改为可选槽位；主攻含防空角色 | 无卡/耗尽时是否继续采购，是否跟随战线 |
| P05 后方囤兵 | 减少重复静态守备、不再按已占目标追加整组后方守军、不在后续列表追加地面静态防御；单次通道防御向前部署；侧线攻击有比例衰减 | 旧任务释放、前线压力时响应；大量无用囤兵仍直接否决 |
| P06 运兵装甲车积压 | 允许再选择运输车、武装车支援候选、战斗任务排除 Vehicule_Transport；不允许额外请求生产运输车，保留当前运输关联 | 载员任务不受干扰、同一车辆卸载后确实回战；本项为未实战验证的实验行为 |
| P07 坦克逐辆送死 | 主攻不再前列两辆最贵坦克；地面组先配置基础角色，坦克通道保留装甲起手并补支援 | 接敌到达间隔和展开；未改局部寻路/阵形，不能宣称完整修复 |
| P08 缺炮火掩护 | 提前可协调的 IsSupport 炮兵，保留地面 NeedSupport 与数量请求 | 同区同时的实际支援与推进，不能用炮击总数替代 |
| P09 攻防无章法 | 三阶段重新安排主攻、增援、侦察、补给及火力，劣势不改为连续堆主攻 | 目标变化、受挫恢复；未虚构动态六阶段状态机 |
| P10 飞机盘旋 | 修正上游匹配；Assault 与其扩展使用原版已有的攻击失败取消选项 | 目标失效、投弹、返航；没有修改飞行物理或添加未开放的超时机制 |
| P11 步兵师对装甲乏力 | 步兵/混合组前列专职 AT，预算考虑运输，不要求缺坦克的卡组等待坦克 | 地形、视野、AT 实际开火和抵抗效果 |
| P12 搭配失衡 | 14 个普通地面池重组，基础角色优先；坦克和直升机分工 | 实际购买/到场组合、库存耗尽与长期资源分配 |

这里的“14 个普通地面池”不含突破专用池；主攻、夺点各一，普通、步兵、合成、坦克各三。

## 耦合控制

- 增强火力不叠加全局风险容忍、机会空袭门槛和射击门槛全面放宽。
- 增加编组能力不叠加强制齐编、提高主攻比例、延长撤退等待；避免把组织性变成囤兵。
- 缺失的角色不设硬性必选；但这只说明配置未强制该槽，不证明运行时绝无采购阻塞。
- 武装运输车实验保留当前载员关联及原运输生产限制。静态检查确认武装/无武装运输标签无交集，但不能证明正在运输中的车辆绝不会被引擎重分配。
- 防空不再用无防空能力单位冒充；同一版未提高飞机冒险程度。
- 不改单位伤害、血量、视野、经济加成或兵种库存来人为堆损失。

## 数据与规则边界

最高难度默认入口和非突破票券覆盖入口均指向修改后的 VeryHardStrategy。后者是针对入口覆盖的防护，不声称已从静态文件完全证明当前每种 UI 规则的原生映射。突破专用攻守调度保持原版；用户已有 Attack-N-Defend Map Pack 也未被改动、停用或启用。若实际场景走突破策略，只共享改动过的宏/常量，不算本版完整策略实测覆盖。

默认卡组费用报告是下界：没有模拟原生标签优先、可用库存、重复角色抢同张卡、开局资金、任务调度、生产与行进时间。SOV_25_Tank 默认卡组没有独立专职 AT 候选，本版可用坦克替代。角色存在和费用可行不等于实际购买合理。

## 实施状态

源配置、可复现应用脚本、离线校验、官方生成、二进制包装核对和可搬运包构成第一版交付。用户要求不控制界面，因此游戏加载、双方实际损失、空袭完成率、囤兵消除及两种规则对局结果均为待实测。不得将本版标为核心目标已完成。
