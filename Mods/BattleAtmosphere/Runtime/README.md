## 使用

只启用 **BattleAtmosphere**，完全退出并重新启动 WARNO，开始新的最高难度单人遭遇战。无需另开 Python 或启用 BAScriptProbe。沿用用户双倍资金设置，没有额外改动收入。

根目录 `version.dll` 自动装入运行组件；原版 EXE/DAT 未修改。仅支持核验过的 revision 201602，要求模组启用、`runtime.ini` 的 `Enabled=1` 以及原生类型和版本检查通过。旧 test3 ZIP 不包含本轮组件与采购更新。研究模组不得放回 Saved Games 模组扫描目录造成 ID 冲突。

## 本轮行为

- 先根据首批真实地面单位识别物理出生侧，不再把地图侧编号直接作为运行阵营编号。不明确时保留原生控制，确认后整局保持一致；`SPACE_ORIENTATION` 记录依据。
- 运输绕路时同时检查实际移动，避免直线距离暂时增加就误判卡住；仍保留真正停滞、接敌与总运输期限的应急处理。

- 宽战线、据点核心限额、共享阵位预约与原生攻击前进延续 preview.4；玩家单位只作为空间占用，不接受下令。
- 载员车辆与步兵绑定，运到所属前沿附近的分散卸载带，候选距估计前沿后 250/400/550 米。各车卸载预约相隔至少 160 米，检查车辆及步兵导航类型；临近到达时允许有限次数追随前沿更新。车辆遇到接战或长时间无进展可应急卸载。
- 下车后步兵继续自己的区段任务，有武器车辆短程跟进；不会为了凑齐编组拉回后方。无武装、炮兵、防空、补给、指挥、航空仍由原生职责管理。
- 局部战术选择包括持续展开、后方赶上、接触推进、随队支援、邻接侧翼推进、突破延伸和受阻换路。新分支保持正向目标，没有固定停住半数部队的轮换。缩短推进路段不等于直接修改单位最高速度。
- 原生坦克任务预算提高，普通池提前加入坦克机会，新增可跳过的单坦克采购任务。保留步兵、侦察、反坦克、防空、炮兵、航空和补给需求，不等待卡组里没有的坦克，也不添加卡外单位。

实际交战继续由原生火力动作处理，普通移动过滤与 4 秒失去续租即归还保护保留。地图窄口、不可达路线和受攻击时的短时集中仍可能出现。

## 观察与未完成项

日志 `last-run.log` 应出现 `SPACE_REVISION combined-front-preview.6`。`FRONT_METRICS` 记录实际宽度、密度、据点核心、后方闲置与交战；`TRANSPORT_ROUTE/DELIVERED/RETARGET/EMERGENCY/RETURN` 记录运送、卸载和失败；`TRANSPORT_STATUS` 是运输计数；`TACTIC_STATUS` 是各分支的规划次数，不等于成功战术次数。`FORCE_MIX` 统计可读取角色的在场数量和首次观察数量，不能当成真实扣款购买事件。

运输前沿来自友军 AI 区段与接战信号，没有接战时使用公开地图几何与推进位置估计，不能保证每种地形都选到最佳掩护。实时资金/库存/排队驱动的完整采购器、自动重新乘车、直接炮兵烟幕调度、基于已见敌军的真正合围尚未接入；当前是采购纠偏与局部正向战术。普通最高难度、双倍资金的实际采购比例和卸载观感仍待实测。

以下为 preview.4/preview.5 的历史极端压力结果，preview.6 未重测该模型：一次将 1000 辆车放进密集 6 列纵队，240 秒只有 536 辆获得路线，preview.4 同条件为 538；两版均未通过快速解堵目标。此已知饱和边界保留在 [压力对照](../Development/combined-1000-stress.json)，不能宣称任意密度都能及时展开。该模型不等于普通高收入连续增援。

完整 4v4、所有卡组/地图、连续换图仍需实际对局覆盖。联网和命令行回放跳过，界面回放完整识别尚未验证。

## 构建与回退

方案与耦合见 [本轮方案](../COMBINED_ARMS_PLAN.md)。运行源码在 `Python/`，嵌入 DLL；只改源码不会改变游戏执行版本。`Development/run_combined_validation.py` 完整构建并运行离线/原生回归；`build_combined_ndf.py` 官方生成采购配置；`install_combined_release.py` 校验后安装；`native_bridge/verify_runtime.py --installed` 核对正式目录回执。

`runtime.ini` 设置 `Enabled=0` 或停用 BattleAtmosphere，重启后生效。`native_bridge/install_runtime.py --remove` 仅删除回执哈希匹配的自有 DLL。preview.4 验收基准在 `Development/archive/accepted-preview4-20261106`，本次安装前完整文件备份为 `Development/archive/installed-before-combined-preview5.zip`。

方向与绕路修复的细节、失败候选和测试边界见 [DIRECTION_FIX.md](../DIRECTION_FIX.md)。preview.6 仅更新运行组件，使用 `Development/install_direction_release.py` 安装已经验证的候选。
